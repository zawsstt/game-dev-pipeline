# 🎮 Game Dev Pipeline — AI 游戏工业化全流程工作室

> 一个自闭环的 AI 游戏工作室管线 Skill，将任意模糊的游戏想法转化为可直接交付给开发团队的完整预研文档包。

## 核心能力

- **12 个固定层 Agent**：覆盖策划 / 美术 / 音效 / 特效 / 动画 / 关卡 / 文案 / 技术 / 数据 / 发行 / 本地化，任何品类强制激活
- **品类动态层 Agent**：根据游戏品类（策略/SLG、Roguelike、养成、叙事、休闲等）自动激活 2-5 个专属 Agent
- **SSP v1.0 协议**：所有 Agent 强制执行"搜索 → 提炼 → 生成"三步闭环，禁止跳过搜索直接输出
- **用户决策门（User Gate）**：5 个关键节点强制暂停，等待用户确认方向后再派发第二层实现任务
- **双层派单机制**：第一层输出规格文档，用户确认后派发第二层实现 Ticket，Sub-Agent 可自主拆解子任务
- **精准修订**：用户否决时只修改被否决的模块，自动识别依赖链级联，不推倒重来

## 工作流总览

```
阶段一  市场搜索 + 结构化反问      →  项目立项书
阶段二  竞品搜索 + 评论抓取        →  竞品拆解报告
阶段三  品类识别 + 动态派生        →  Sub-Agent 团队 + Tickets
阶段四  运控层（看板 + 播报 + 交付）→  全员设计/规格文档
        ├─ 批次 A（并行）：PACING / UX / ART / AUDIO / VFX / ANIM / LEVEL / COPY / L10N + 动态层
        ├─ 批次 B（串行）：TECH 技术评估（批次A全部PASS后）
        └─ 用户决策门 GATE → 第二层实现派单 / 精准修订
阶段五  QA 核查                  →  集成一致性确认报告
阶段六  版本分层                  →  MVP / v1.0 / v1.x 路线图
        └─ 批次 C（串行）：DATA 数据埋点 / PUBLISH 发行运营
阶段七  测试用例生成              →  测试计划文档
阶段八  风险登记                  →  P0/P1/P2 风险登记簿
```

## 固定层 Agent 一览

| 代号 | Agent | 职责 | 批次 |
|------|-------|-----|------|
| PACING | 进程感知 | 节奏 / 里程碑 / 成就感设计 | A |
| UX | UI/UX | 交互状态机 / 组件规范 | A |
| ART | 美术总监 | 视觉风格 / 资源规格 / 美术管线 | A |
| AUDIO | 音效设计 | BGM 分轨 / SFX 清单 / 自适应音乐 | A |
| VFX | VFX 特效 | 粒子规格 / 屏幕特效 / GPU 预算 | A |
| ANIM | 动画 | 角色动作集 / UI 动效 / 状态机 | A |
| LEVEL | 关卡设计 | 四段式骨架 / 空间引导 / 验收标准 | A |
| COPY | 文案/叙事 | 文案风格 / UI 文案 / 剧情大纲 | A |
| L10N | 本地化 | 多语言管理 / 文化适配（可选）| A |
| TECH | 技术评估 | 可行性审查 / 性能预算 / 风险登记 | B（串行）|
| DATA | 数据埋点 | 核心指标 / 埋点清单 / 留存漏斗 | C（串行）|
| PUBLISH | 发行运营 | 上线 Checklist / 渠道策略 / 危机预案 | C（串行）|

## 快速启动

```
[系统] 你是游戏工业化 Master Agent。
请按 master-agent.md 八阶段 SOP 处理以下游戏想法：

{你的游戏想法}

已知项目上下文（可选）：
- 品类：{e.g. 策略/SLG}
- 引擎：{e.g. Unity 2022 LTS}
- 团队规模：{e.g. 5人}
- 目标平台：{e.g. PC Steam}
```
